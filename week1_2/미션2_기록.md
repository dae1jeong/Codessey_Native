- ChatGPT / GPTAI_채팅.png
- 좁혀서 적은 한 문장:  
    영화 티어리스트에서 ‘센과 치히로의 행방불명’, ‘어벤져스: 엔드게임’, ‘토이 스토리’ 세 영화만 클릭하거나 드래그해도 S·A·B·C 등급 영역으로 이동하지 않는 문제를 해결해 줘. 다른 기능과 화면 디자인은 그대로 유지하고, 외부 파일이나 서버 없이 실행할 수 있도록 수정해 줘.
- 좁히려고 해 본 것과 결과:  
    처음에는 세 영화에서만 문제가 발생한다는 공통점을 확인했다. AI에게 기획서와 현재 동작하는 HTML 파일을 함께 제공하고, 문제가 발생하는 영화 제목에 공통적으로 포함된 공백에 주목하도록 했다. AI는 기존 코드에서 영화 제목을 HTML 문자열에 직접 삽입하는 방식이 문제일 가능성을 제시했다. 이후 해당 부분을 수정한 HTML 파일을 제공받았다.
- AI가 말한 원인과, 그 설명을 직접 확인한 결과:  
    기존 코드에서는 영화 카드 생성 시 `item.id`를 HTML 문자열에 직접 연결하여 `data-id` 속성에 삽입하고 있었다. 이때 영화 제목에 공백이 포함되면 HTML 속성이 의도한 대로 처리되지 않아, 클릭이나 드래그 후 영화 ID를 찾지 못하는 문제가 발생할 수 있었다. 기존 코드의 카드 생성 부분을 직접 확인했고, 영화 제목을 HTML 문자열에 연결하는 방식을 사용하고 있음을 확인했다. AI의 설명에 따라 DOM 요소를 직접 생성하고 `dataset.id`에 ID를 저장하도록 변경했다. 또한 영화 제목은 `textContent`로 표시하도록 수정했다.
