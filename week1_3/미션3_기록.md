- 아무도 말하지 않았는데 내가 찾은 것:
  1. 제목 칸에 공백(스페이스)만 넣고 '추가'를 눌러도 빈 카드가 생김. 코드가 trim은 하지만 빈 문자열 여부를 확인하지 않아 AI(3)과 같은 뿌리의 문제.
  2. 같은 제목의 영화를 중복으로 추가할 수 있음(중복 검사 없음). 같은 영화가 여러 장 생겨 취향 정리 목적과 어긋날 수 있음.
  3. 모바일 터치 환경에서는 드래그 이동이 동작하지 않음(HTML5 drag 기능은 터치 미지원). 휴대폰에선 '카드 선택 + 등급 버튼' 방식만 사용 가능.

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:
  - AI(2)처럼 "그럴듯하지만 실제 코드와 다른" 피드백을 어떻게 걸러냈는지 나누고 싶음. 직접 해 보기 전에는 믿지 않는다는 원칙이 왜 중요한지 사례로 공유하고 싶어서.
