# 민수 님께 보내는 피드백

**잘된 점:** 등급마다 색이 뚜렷해서 S·A·B·C 칸이 한눈에 구분됐고, 상단에 "8편 중 3편 나눔"처럼 진행도가 나와서 얼마나 남았는지 바로 알 수 있었습니다. 카드를 끌 때 칸 색이 살짝 바뀌어 놓을 위치가 잘 보였고, 드래그와 "카드 선택 + 등급 버튼" 두 가지 조작 방식을 모두 지원하는 점이 좋았습니다.

## 고치면 좋을 점

**1.**
- **본 것:** 영화를 S·A 칸에 나눈 뒤 페이지를 새로고침했더니 모든 영화가 다시 미분류로 돌아갔습니다.
- **기준:** 기획서의 "같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다"
- **제안:** localStorage에 배치 상태를 저장하고, 페이지를 열 때 저장된 값을 불러오도록 하면 좋겠습니다.

**2.**
- **본 것:** 제목 칸을 비운 채(또는 공백만 넣고) '추가'를 눌렀더니 글자 없는 빈 카드가 생겼습니다.
- **기준:** 기획서의 "제목을 입력하면 새 영화 카드가 생깁니다"
- **제안:** 제목이 비어 있으면 카드를 만들지 말고 "제목을 입력해 주세요" 같은 안내를 띄우면 좋겠습니다.

**3.**
- **본 것:** 브라우저 창 폭을 좁혔더니 내용의 오른쪽이 잘려서 보이지 않았습니다. (`.page`가 960px 고정폭이고 `overflow-x: hidden`이 걸려 있음)
- **기준:** 기획서의 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다"
- **제안:** 고정폭 대신 `max-width` + 가변폭으로 바꾸고, 좁은 화면용 스타일을 추가하면 좋겠습니다.

**4.**
- **본 것:** 미분류 영화가 등급 칸들 맨 아래에 있어, 카드를 S칸까지 끌어올리려면 화면을 함께 스크롤해야 했습니다.
- **기준:** 기획서에 위치 규정은 없으나, 직접 써 보니 드래그 이동이 불편했습니다.
- **제안:** 미분류 칸을 등급 칸 위쪽이나 옆에 두면 끌어 옮기기 더 편할 것 같습니다.

---

> 참고로 아래는 반영하지 않았습니다.
> - 동료가 말한 "'처음으로'가 추가한 영화를 안 지운다"는 직접 해 보니 추가한 영화도 함께 지워져 기획서대로 잘 동작했습니다.
> - C칸 삭제·포스터 추가·카드 색 변경은 기획서의 목적이나 "HTML 한 장" 조건과 맞지 않아 반영하지 않았습니다.
