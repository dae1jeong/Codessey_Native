## 수정 기록

### 수정 기록 1 — 오늘 마감 숫자만 빨간색으로 강조

- **발견한 문제:** 대시보드의 '오늘 마감' 수치가 다른 통계와 비슷한 색상으로 표시되어 긴급한 일정을 빠르게 구분하기 어려웠다.
- **AI에게 전달한 요청:** "대시보드 가장 상단에 완료, 7일이내, 오늘마감, 전체일정이 있는데 오늘마감에 해당하는 숫자만 빨간색으로 보이게 코드를 수정해줘. 한글은 그대로 검정을 유지하고 숫자만 빨간색으로."
- **수정 후 테스트 결과:** `#s-today` 숫자 요소에만 빨간색 스타일이 적용되도록 수정했다. '오늘 마감'이라는 한글 항목명은 기존 글자색을 유지하며, 다른 통계 숫자에도 영향이 없도록 구성했다. 최종 HTML 코드에서 해당 CSS 규칙을 확인했다.
- **수정 이유:** 오늘 처리해야 할 일정의 중요도를 강조하면서 다른 통계와 시각적으로 구분하기 위해서다.

### 수정 기록 2 — 완료 취소(복구) 버튼 선명하게 변경

- **발견한 문제:** '최근 완료' 영역의 완료 취소 버튼이 연한 색상과 얇은 표시 때문에 눈에 잘 띄지 않았다.
- **AI에게 전달한 요청:** "최근완료에서 다시 완료취소하는 버튼을 두껍고 더 진한 검은색으로 해줘. 눈에 조금 더 잘 띄게."
- **수정 후 테스트 결과:** 완료 취소 버튼의 색상을 짙게 하고 글자 두께·크기·획을 강화했다. `data-act="undo"` 버튼에만 별도 스타일이 적용되어 기존 완료 처리 기능과 다른 버튼의 스타일은 유지되도록 했다. 최종 HTML 코드에서 수정된 스타일을 확인했다.
- **수정 이유:** 사용자가 완료 상태를 실수로 지정했을 때 복구 기능을 쉽게 발견하고 사용할 수 있도록 하기 위해서다.

### 수정 기록 3 — 상단 로고 변경 및 불필요한 문구 삭제

- **발견한 문제:** 왼쪽 상단의 기존 영문 브랜드 문구와 로고가 생활 관리 서비스의 친근한 분위기를 충분히 전달하지 못했다.
- **AI에게 전달한 요청:** "Due :)로 하자. 그리고 문구는 삭제하고 로고만 하자. Due :)만 하는걸로 수정해서 html뽑아줘."
- **수정 후 테스트 결과:** 왼쪽 상단 브랜드 영역을 **`Due :)`** 로 변경하고 부가 문구를 삭제했다. 첨부된 수정 HTML의 브랜드 영역에서 `Due :)`만 표시하도록 작성된 것을 확인했다.
- **수정 이유:** 이름을 간결하게 정리하고 웃는 표정의 기호를 더해 서비스가 부드럽고 친숙하게 느껴지도록 하기 위해서다.

## 사용자 테스트 — 색상 테마 개선

- **테스트 참여자와 요청한 작업:** 서비스 제작자가 직접 기존 화면의 색상과 가독성을 검토했다. 기존의 아주 연한 회색·남색 조합을 보고, 화면 구성과 기능은 유지하면서 더 따뜻한 색상으로 변경하도록 AI에 요청했다. 
- **사용자의 행동과 질문:** "지금은 아주 연한 회색과 남색의 조합인데 이걸 조금 더 따뜻한 느낌의 색채로 바꾸고 싶어. 초록색계열과 아이보리 조합으로 바꿔줘. 초록색도 진한거 말고 아이보리와 잘 어울리는 색으로"라고 요청했다. 이후 기존 HTML 파일을 전달해 해당 디자인을 기준으로 수정하도록 했다.
- **받은 피드백:** 기존 남색·회색 조합보다 **아이보리와 채도가 낮은 부드러운 초록색**이 더 따뜻하고 편안한 인상을 줄 것이라는 제작자의 의견이 있었다. 진한 초록색은 피하고 아이보리와 조화로운 세이지 그린을 사용하기로 했다.
- **반영 내용과 결과:** 배경을 따뜻한 아이보리 계열로, 사이드바와 주요 버튼·강조 요소를 세이지 그린 계열로 변경하는 디자인을 적용했다. 텍스트와 테두리도 전체 색상에 맞게 조정하고, 앞서 수정한 **오늘 마감 숫자의 빨간색 강조**와 **복구 버튼의 선명도**, **`Due :)` 로고**는 유지하는 방향으로 정리했다. 최종 테마 파일은 `due_v5.html`이다.
