# Due :) — 생활 마감일 관리 서비스

## 대상 사용자

- 택배 반품 기한, 쿠폰 만료일, 구독 갱신일, 예약일, 과제 제출일 등 다양한 마감일을 관리해야 하는 대학생, 직장인 및 일반 사용자
    
- 여러 서비스와 일정에 흩어진 마감일을 한곳에서 확인하고 관리하고 싶은 사람
    

## 사용 목적

- 일상생활에서 놓치기 쉬운 다양한 마감일을 한 페이지에서 통합 관리한다.
    
- 마감일까지 남은 날짜(D-Day)를 자동으로 계산하여 중요한 일정을 미리 확인할 수 있도록 한다.
    
- 일정의 등록, 수정, 삭제, 완료 처리를 통해 마감일 관리 작업을 간편하게 수행한다.
    

## 화면 구성과 동작

- **서비스 로고 및 화면 스타일**

    - 왼쪽 상단에는 `Due :)` 로고만 표시하며, 기존 로고의 부가 문구는 제거한다.

    - 전체 배경은 따뜻한 아이보리, 주요 강조 색상은 부드러운 세이지 그린으로 구성한다.


- **대시보드**
    
    - 전체 일정 수, 오늘 마감 일정 수, 7일 이내 마감 일정 수, 완료한 일정 수를 표시한다. 오늘 마감의 숫자만 빨간색으로 강조하고 제목은 일반 텍스트 색상을 유지한다.
        
    - 오늘의 일정, 다가오는 일정, 최근 완료한 일정을 구분하여 보여준다.
        
- **전체 일정**
    
    - 등록된 모든 일정을 목록 형태로 표시한다.
        
    - 제목과 메모를 검색할 수 있다.
        
    - 카테고리와 진행 상태에 따라 일정을 필터링할 수 있다.
        
- **캘린더**
    
    - 월별 달력을 표시하고 날짜별 등록된 일정을 확인할 수 있다.
        
    - 특정 날짜를 선택하면 해당 날짜의 일정과 상세 정보를 보여준다.
        
- **완료한 일정**
    
    - 완료 처리한 일정을 별도로 모아서 보여준다.
        
    - 완료 상태를 취소하면 진행 중인 일정으로 되돌릴 수 있다. 최근 완료 영역의 복구(완료 취소) 버튼은 굵고 선명한 짙은 검정색으로 표시한다.
        
- **일정 추가 및 수정**
    
    - 일정 제목, 카테고리, 마감일, 선택 사항인 메모를 입력할 수 있다.
        
    - 등록된 일정의 내용을 수정하거나 삭제할 수 있다.
        
    - 삭제 전 확인 절차를 제공한다.
        

## 필요한 자료

- 서비스 이름: Due :)
    
- 서비스 설명: 일상생활의 다양한 마감일을 통합 관리하는 개인 일정 관리 서비스
    
- 일정 카테고리: 쇼핑, 금융, 구독, 예약, 학업, 기타
    
- 일정 데이터 항목: 제목, 카테고리, 마감일, 메모, 완료 여부
    
- 첫 실행 시 활용할 예시 일정: 택배 반품, 쿠폰 만료, 구독 갱신, 학업 일정 등
    
- 디자인 방향: 따뜻한 아이보리 배경과 채도가 낮은 세이지 그린 포인트를 조합한 편안하고 깔끔한 UI. 카드에는 흰색을 사용하고 텍스트는 차분한 짙은 색으로 표시한다.
    
- 구현 방식: HTML 파일 하나에 CSS와 JavaScript를 포함하고, 브라우저 LocalStorage를 사용
    
- 외부 이미지나 별도 라이브러리 없이 기본 HTML, CSS, JavaScript로 구현
    

## 필수 기능(완료기준)

이번 구현에서 반드시 제공해야 하는 기능이다.

1. **일정 등록:** 제목, 카테고리, 마감일, 메모를 입력하여 새로운 일정을 등록한다.
    
2. **D-Day 자동 계산:** 현재 날짜를 기준으로 마감일까지 남은 날짜를 자동 계산한다. 마감일이 지나면 D+N 형태로 표시한다.
    
3. **대시보드:** 전체 일정, 오늘 마감 일정, 7일 이내 마감 일정, 완료한 일정의 요약 정보를 제공한다. 오늘 마감의 숫자만 빨간색으로 표시한다.
    
4. **일정 관리:** 기존 일정의 수정, 삭제, 완료 처리가 가능하며 완료 처리를 취소할 수 있다. 최근 완료의 복구 버튼은 진하고 굵게 표시한다.
    
5. **검색:** 일정 제목과 메모를 기준으로 원하는 일정을 검색할 수 있다.
    
6. **필터링:** 쇼핑, 금융, 구독, 예약, 학업, 기타 카테고리 및 진행 상태에 따라 일정을 필터링할 수 있다.
    
7. **캘린더:** 월별 달력에서 날짜별 일정을 확인하고 특정 날짜의 상세 일정을 조회할 수 있다.
    
8. **데이터 저장:** LocalStorage를 활용하여 일정 정보를 자동 저장하고 페이지를 새로고침해도 기존 데이터를 유지한다.

9. **최종 디자인:** `Due :)` 로고만 상단에 표시하고, 아이보리·세이지 그린 중심의 색상 체계를 적용한다. 기존 화면 구조와 일정 관리 기능은 유지한다.
    

## 추가 기능

필수 기능이 정상적으로 구현된 이후 적용하거나 향후 확장할 기능이다.

1. **브라우저 알림:** 사용자가 알림 권한을 허용하면 페이지가 열려 있는 동안 마감일 알림을 제공한다.
    
2. **첫 실행 예시 데이터:** 서비스 사용 방법을 쉽게 이해할 수 있도록 첫 실행 시 예시 일정을 자동 등록한다.
    
3. **로그인 및 클라우드 동기화:** 여러 기기에서 동일한 일정 데이터를 사용할 수 있도록 계정과 서버 기반 저장 기능을 추가한다.
    
4. **이메일 및 문자 자동 수집:** 이메일이나 문자 메시지에서 마감일 정보를 추출하여 일정 등록을 지원한다.
    
5. **AI 기반 일정 관리:** AI를 활용하여 일정 카테고리를 자동 분류하거나 일정 정보를 자동으로 입력하는 기능을 추가한다.
    

## 한계 및 비목표

1. 일정 데이터는 브라우저의 LocalStorage에 저장되므로 현재 브라우저와 기기에 종속된다. 브라우저 데이터 삭제 시 저장된 일정이 사라질 수 있으며, 기기 간 데이터 동기화는 지원하지 않는다.
    
2. 브라우저 알림은 사용자가 권한을 허용하고 페이지가 열려 있는 동안 제공하는 것을 목표로 한다. 브라우저가 닫혀 있거나 페이지가 종료된 상태에서의 안정적인 백그라운드 알림은 지원하지 않는다.
    
3. 이번 구현에서는 로그인, 서버 연동, 이메일 및 문자 메시지 자동 수집, AI 기반 일정 자동 분류 및 등록 기능을 제공하지 않는다.
    

## 검증 방법

- **디자인 및 사용성 검증**

    - 오늘 마감 숫자만 빨간색인지, 최근 완료 복구 버튼이 명확히 보이는지, 왼쪽 상단에 `Due :)`만 표시되는지 확인한다.

    - 아이보리·세이지 그린 테마가 대시보드·버튼·달력 등 주요 화면에 일관되게 적용되는지 확인한다.

    - 디자인 변경 전후에 일정 추가·수정·삭제, 완료·취소, 검색·필터, 캘린더와 저장 기능이 유지되는지 확인한다.


- **D-Day 계산 결과 수동 검증**
    
    - 오늘, 내일, 7일 후, 어제에 해당하는 날짜를 각각 일정의 마감일로 등록한다.
        
    - 서비스 화면에 표시되는 D-Day 값을 확인한다.
        
    - 기기의 현재 날짜를 기준으로 달력에서 날짜 차이를 직접 계산한 결과와 서비스의 표시 값을 비교한다.
        
    - 모든 일정에서 수동 계산 결과와 서비스의 D-Day 표시가 일치하는지 확인한다.
